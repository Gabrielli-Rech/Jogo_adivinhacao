## 🎮 Jogo Adivinhação

Bem-vinda(o) ao “Jogo Adivinhação” — onde você testa suas palpites, enfrenta a sorte e se diverte.
Este repositório reúne o projeto “Jogo Adivinhação”, desenvolvido para praticar lógica, estruturas de controle, input/output em linha de comando (ou interface simples) e demonstrar domínio técnico com um toque de gamificação.

## ✨Descrição

O objetivo deste jogo é simples, porém viciante: o computador escolhe um número secreto e você precisa adivinhar. A cada tentativa, recebe dicas (“maior”, “menor”), até acertar.
Esse projeto mostra:

lógica de fluxo (laços, condicionais)

tratamento de entradas do usuário

geração de valores aleatórios

mensagem de feedback interativo

estrutura de projeto limpa e comentada

(se aplicável) escalabilidade para versões mais robustas (GUI, web, ranking, etc.)

## ⚙️ Instalação & Como Jogar

# Clone o repositório
git clone https://github.com/Gabrielli-Rech/Jogo_adivinhacao.git
cd Jogo_adivinhacao

# (Se Python) Crie ambiente virtual
python3 -m venv venv
source venv/bin/activate        # Linux/Mac
# ou: venv\Scripts\activate     # Windows

# Instale dependências (se houver)
pip install -r requirements.txt

# Execute o jogo
python jogo_adivinhacao.py      # ou o nome correto do arquivo
